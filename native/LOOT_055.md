# 0.5.5 地面物资

雷达底部新增「◇ 物资」按钮，打开独立液态玻璃筛选面板。支持总开关、物品种类、种类搜索、全部显示/隐藏，以及稀有度筛选；设置写入本机浏览器 `radaer.tactical.v1`，与人物显示开关独立。移动端面板可滚动，与人物和设置面板互斥。

面板现采用独立宽屏双栏布局：左侧显示大类及子类别，各有总开关；右侧显示当前类别的所有目录物资，可按名称或 ID 搜索、逐项启用/关闭，以及本类全选/全不选。每页最多 60 项，卡片底色按物资稀有度着色。手机保留左右结构，右侧改为单列卡片，两侧独立滚动。

筛选关系：物资总开关、大类、子类别、单项、稀有度须全部允许才显示。关闭分类总开关不会改变单项选择；重新打开后恢复原有选择。新增 `lootGroups`、`lootItems` 和当前类别偏好，兼容已有类别及稀有度设置。「类别全开/全关」仅调整分类总开关；「本类全选/全不选」调整整个类别的单项选择，不受当前搜索和分页限制。

`radar/items.json` 从用户提供的 `sora_items.json` 导入：3,456 个名称、65 个分类。使用 `pc/sc/scCN` 分类，收集品进一步按 `detail.type` 分为工艺藏品、资料情报、电子物品、工具材料等。名称颜色按 grade 1–6 对应白、绿、蓝、紫、金、红；grade 0 或未知等级用灰色。未收录 ID 显示「未知物品 ID」，不推测名称。物品数据以字符串 ID 匹配，避免整数精度损失。

原目录保留在用户下载目录，运行包使用精简后的本地 JSON，无需外网。开发时重新导入：

```powershell
native/build/decoder-env/Scripts/python.exe native/tools/generate_loot_catalog.py C:/path/sora_items.json
```

## C++ 数据链路

- 在已有 UE 包/可靠 Bunch 排序和分片重组之后，按导出的 `BP_InventoryPickup` 类选择物资布局。NewActor 使用量化标志读取坐标，不套用 Character 的额外字节。
- 解析 `InventoryIdName`、`InventoryGID`、`StackCount`、隐藏状态、`ItemState`、ReplicatedMovement 和 `PickupItemInfo` 原生结构。物品原生结构及枪械附属结构采用有界读取；遇到未知 archive/多态扩展停止该部分。
- 完整块才用于确认隐藏/清零等移除；已验证的非原生前缀可保留。截断/非法字段不提交状态。物资块的拒绝次数单独统计，不污染人物移动连续性。
- 休眠、离开同步范围保留最后位置；销毁、关卡卸载、tear-off、物品隐藏、数量为零或 ItemState=5 移除。支持新通道上的 GUID-only 销毁通知。
- 战斗流、bank epoch、采集重置隔离物资缓存；15 秒战斗静默或停止时隐藏，原流恢复时使用该流自己的状态。
- `loot_state` 写入采集日志；`decode-players` 额外输出 `loot.jsonl`。`/api/live` 提供当前战斗的 `loot` 对象。
- 物资名称先绘到独立缓存 Canvas，地图移动/缩放、筛选或物资变化时重绘，再置于人物图层下方。

范围：只显示网络中已获得 ID 和有效位置的地面物资。未下发 ID 的对象不虚构名称，箱内未知内容不显示。本次未移植完整背包交易追踪；如果服务器没有发送可识别的地面移除证据，会保留最后状态直到切局/重置。

## 验证

22 项 CTest 通过，包括原生协议、物资布局与原版对照、截断拒绝、休眠/销毁/清零、原生结构独立 ID、切流/换 bank、HTTP live 输出及静默清理、分类与稀有度开关。实际页面 JS 用 Node VM 验证了名称绘制、缓存复用、开关和服务端移除；未进行浏览器视觉验收。

对既有 `web-1792385995738-484d250f.jsonl` 离线回放：95 个物资块完整解析，0 个物资块拒绝；与原版对照的 ID/GID、数量、状态无差异。得到 49 个有位置的物资对象，其中 31 个具备物品 ID；其余未收到可确认的 ID，不绘制。人物/本人/下行本人、运动和质量输出与 0.5.4 基线逐字节一致；原有 10 个错误和 11 个警告保持不变。

更新含 C++ 可执行文件及静态资源。关闭现有服务后重新运行 `start.cmd` 或 `start-admin.cmd`，再刷新雷达页面生效。
