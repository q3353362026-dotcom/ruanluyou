# 0.5.3 界面与默认配置

- 控制台与独立雷达使用液态玻璃样式：静态渐变、半透明面板、背景模糊、高光边框。保留响应式布局、键盘焦点和不支持背景模糊时的实色回退；雷达 canvas 不添加模糊或透明滤镜。
- 暂存人物的头像、朝向箭头和文字保持正常亮度，不再减半透明度。虚线圈和“暂存”文字仍区分最后有效位置；保留、死亡清理、断连宽限与插值逻辑不变。
- WebUI 默认勾选 TCP 接入，服务端 API 缺省配置同样启用；端口仍为 65010。显式关闭有效，刷新运行中的会话会恢复该会话设置。打开页面不启动采集；命令行采集默认值不变。
- 正在使用的程序不覆盖、不停止。构建后的 `native/build/radaer-native.pending.exe` 在关闭旧服务并重新运行根目录启动脚本时自动安装，旧程序备份为 `radaer-native.previous.exe`。仍有旧服务运行时启动脚本提示先关闭。

验证使用真实雷达页面脚本的模拟绘制/轮询测试，以及模拟 WinDivert 驱动的 HTTP 集成测试。TCP 缺省开启与显式关闭仅做预检；合成采集显式关闭 TCP，不接管实际网络连接。
